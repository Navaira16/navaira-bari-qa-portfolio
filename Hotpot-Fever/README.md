# Hotpot Fever — Manual QA Case Study

## Project Overview

**Project:** Hotpot Fever Website  
**Website:** https://www.hotpotdelivery.pk/  
**Project Type:** Independent Client Project  
**Role:** Website Planning, AI-Assisted Development, Deployment & Manual QA

## Project Background

Planned, developed, and deployed a website for Hotpot Fever, a food business based in Pakistan, using AI-assisted development tools.

The project involved organizing website content, structuring pages, and supporting the customer journey.

## Testing Objectives

- Verify website navigation and page accessibility.
- Check the display of website content and business information.
- Validate links and customer interaction workflows.
- Check website presentation across desktop and mobile screens.
- Identify functional and UI inconsistencies.

## Testing Approach

Manual testing focuses on website functionality, usability, navigation, and responsive presentation.

Detailed test cases, actual execution results, and bug reports will be documented separately.

## Project Status

Case study documentation in progress.

Manual test cases were executed to evaluate website functionality, navigation, customer interaction workflows, and responsive presentation. Test results and identified issues are documented as part of this QA case study.
