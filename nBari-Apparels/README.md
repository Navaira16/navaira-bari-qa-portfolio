# nBari Apparels — Manual QA Case Study

## Project Overview

**Project:** nBari Apparels E-commerce Website  
**Website:** https://nbariapparels.com  
**Project Type:** Live E-commerce Website  
**Role:** Founder, Website Planning, AI-Assisted Development & Manual QA

## Project Background

I planned, designed, and launched the official e-commerce website for my abaya brand using AI-assisted development tools.

The website showcases abayas and accessories and supports customer enquiries and ordering through WhatsApp.

## Testing Objectives

- Verify website navigation and page accessibility.
- Validate product listings and product information.
- Check responsive layouts on desktop and mobile devices.
- Validate WhatsApp ordering and customer enquiry workflows.
- Identify functional and UI inconsistencies.

## Testing Approach

Manual testing focuses on customer journeys, functional behavior, usability, and responsive presentation.

Testing areas include navigation, product pages, mobile layouts, and the WhatsApp ordering journey.

Detailed manual test cases, execution results, and bug reports will be documented separately as part of this QA portfolio.
